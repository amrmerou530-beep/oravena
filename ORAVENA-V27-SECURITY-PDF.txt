ORAVENA V27 — Security & PDF Report
===================================

طريقة الرفع
-----------
1. فك ضغط الحزمة.
2. ارفع جميع الملفات والمجلدات إلى جذر مستودع GitHub Pages.
3. بعد اكتمال الرفع نفّذ تحديثًا قويًا للصفحة.
4. لا يحتاج هذا التحديث إلى تشغيل SQL جديد.

الحماية المضافة
---------------
- سياسة Content Security Policy تمنع تحميل أكواد واتصالات غير مصرح بها.
- السماح بالاتصال بقاعدة Supabase فقط من النطاق الرسمي.
- منع تشغيل الموقع داخل iframe خارجي لتقليل محاولات الخداع والنقر الخفي.
- عدم تخزين صفحات النظام وتسجيل الدخول وملفات المصادقة في ذاكرة التطبيق المؤقتة.
- تسجيل خروج تلقائي بعد 30 دقيقة من عدم الاستخدام.
- مزامنة تسجيل الخروج بين علامات التبويب المفتوحة.
- تقرير البيانات الكامل متاح للمدير الرئيسي فقط.
- قاعدة البيانات ما زالت تعتمد على RLS والصلاحيات المحفوظة في Supabase.
- ملفات الموقع لا تحتوي على مفتاح service_role أو sb_secret؛ المستخدم هو المفتاح العام المسموح للمتصفح فقط.

تقرير PDF
---------
- استبدال تصدير JSON بتقرير قابل للطباعة أو الحفظ PDF.
- شعار ORAVENA في رأس التقرير وعلامة مائية خفيفة بالخلفية.
- ملخص عدد المرضى والمواعيد والمدفوع والمتبقي.
- جداول مرتبة لملفات المرضى والمواعيد والجلسات وخطط العلاج.
- تنبيه واضح بأن التقرير سري وللاستخدام الإداري.
- عند الضغط على «تصدير تقرير PDF» اختر «حفظ بصيغة PDF» من نافذة الطباعة.

مهم
----
- حماية البيانات الحقيقية تعتمد على صلاحيات Supabase وRLS، وليس على إخفاء كود الواجهة.
- لا تضع مفتاح service_role أو sb_secret داخل أي ملف يُرفع إلى GitHub.
