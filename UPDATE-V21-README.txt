ORAVENA V21 — خطوات التحديث
============================

1) ارفع كل ملفات هذه الحزمة إلى مستودع GitHub الجديد مع استبدال الملفات القديمة.
2) افتح Supabase > SQL Editor.
3) شغّل الملف التالي مرة واحدة فقط:
   supabase/ORAVENA-TOOTH-APPOINTMENTS-SERVICES-V21.sql
4) يجب أن تظهر الرسالة:
   ORAVENA tooth, appointments and services v21 is ready
5) افتح الموقع وسجّل الخروج ثم الدخول، وبعدها نفّذ تحديثًا قويًا للصفحة.

ما الذي يصلحه V21؟
- حفظ خريطة أسنان واحدة وأحدث حالة لكل سن.
- إظهار الخريطة للمريض للقراءة فقط.
- ربط المواعيد القديمة والجديدة بحساب المريض الصحيح.
- تحديث حالة الموعد تلقائيًا في حساب المريض عند الرجوع للموقع، وكل 15 ثانية أثناء فتحه.
- إظهار الخدمات النشطة من قسم الخدمات فقط داخل نموذج الحجز.
- منع إرسال اسم خدمة خارجي غير موجود في الخدمات النشطة.
- إضافة «غير محدد» و«إدخال يدوي…» لاختيارات لوحة الإدارة.

مهم:
- ملف SQL لا يصفّر المرضى أو المواعيد أو الحسابات.
- عند وجود أكثر من خريطة قديمة لنفس المريض، يحتفظ بأحدث خريطة فقط.
