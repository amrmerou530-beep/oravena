ORAVENA V25 — Simplified Patient Files
======================================

طريقة الرفع
-----------
1. فك ضغط ملف ZIP.
2. ارفع كل الملفات والمجلدات كما هي إلى جذر مستودع GitHub Pages.
3. لا تحذف مجلد assets أو supabase أو أي ملف JavaScript.
4. بعد اكتمال الرفع افتح الموقع واعمل تحديثًا قويًا للصفحة.

مهم
----
- لا يحتاج هذا التحديث إلى تشغيل ملف SQL جديد.
- إعدادات Supabase وتسجيل الدخول والحسابات الحالية محفوظة كما هي.
- الأقسام القديمة المخفية لم تُحذف بياناتها من قاعدة البيانات.
- ميزة تثبيت الموقع كتطبيق تعمل من رابط HTTPS مثل GitHub Pages.

أهم التغييرات
-------------
- الأقسام الرئيسية أصبحت: لوحة المتابعة، الخدمات، المواعيد، ملفات المرضى، المستخدمون والصلاحيات، التقارير، سجل العمليات، الإعدادات.
- تم إخفاء أقسام الوصفات، الأشعة، المخزون، المعامل، الرسائل، والحسابات العامة.
- ملف المريض يجمع: آخر العمليات، المواعيد، الجلسات، صور الفم، خطة العلاج، خريطة الأسنان، وحساب المريض.
- الأقسام داخل ملف المريض قابلة للفتح والغلق لتجنب ازدحام الصفحة.
- صفحة ملفات المرضى تحتوي على بحث وفلتر عمر وبطاقات منفصلة لكل مريض.
- نموذج الحجز الخارجي يطلب الاسم والسن والخدمة فقط، مع إمكانية إضافة طلب آخر.
- نموذج الجلسة يحتوي على الخدمة والمبلغ والمدفوع والحالة والملخص الظاهر للمريض.
- حساب المريض يُحسب من مبالغ الجلسات والمدفوع والمتبقي.
