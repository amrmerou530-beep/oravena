ORAVENA V20 — الحفظ الصارم لكل بيانات الموقع

نفّذ خطوتين فقط:

1) ارفع جميع ملفات هذه الحزمة إلى GitHub واستبدل الملفات القديمة.

2) افتح Supabase > SQL Editor وشغّل الملف كاملًا مرة واحدة:
   supabase/ORAVENA-STRICT-PERSISTENCE-V20.sql

يجب أن تكون آخر نتيجة:
ORAVENA strict persistence v20 is ready

بعدها:
- سجّل خروجًا من الموقع ثم ادخل مرة أخرى.
- نفّذ تحديثًا إجباريًا Ctrl + Shift + R.
- أضف سجلًا، أغلق الموقع، وافتحه من جهاز آخر بنفس الحساب.

V20 يجعل Supabase المصدر الوحيد لبيانات التشغيل:
- الحساب وملف المريض.
- المرضى والعملاء.
- المواعيد والجلسات وبدء الجلسة.
- خريطة الأسنان وخطط العلاج والوصفات.
- الصور والأشعة والرسائل.
- الفواتير والدفعات والمصروفات والاسترداد.
- المخزون والمعامل.
- الخدمات وإعدادات الموقع.
- المستخدمون والصلاحيات والتنبيهات.

لن يعرض الموقع رسالة نجاح إلا بعد تأكيد الخادم وإعادة قراءة السجل.
اللغة والقسم المفتوح فقط إعدادات واجهة محلية ولا تعتبر بيانات عيادة.

مهم: لا تشغّل ملفات V16 أو V17 أو V18 أو V19 منفصلة مع هذه الحزمة.
لا تضع sb_secret أو service_role داخل ملفات الموقع.
